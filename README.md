# GitHub Developer Analyzer

Point it at any GitHub username and get back a full profile breakdown: language usage, an activity-based score, top repositories, and AI-generated feedback on strengths, weaknesses, and suggestions — powered by a locally-hosted LLM.

## Features

- **Profile lookup** — pulls avatar, follower count, public repo count, and bio via the GitHub REST API
- **Language breakdown** — visualizes the language distribution across a user's repositories
- **Profile score** — a computed score and skill level (Beginner → Expert) based on activity and repo quality
- **Top repositories** — the user's most-starred repos, with language and fork count
- **AI recommendations** — on-demand strengths / weaknesses / suggestions generated by a local LLM via Ollama, no external API calls
- **Light / dark mode** — theme toggle with system preference detection and persistence

## Tech stack

| Layer      | Technology                              |
|------------|------------------------------------------|
| Frontend   | React, TypeScript, Tailwind CSS, Vite    |
| Backend    | Spring Boot (Java)                       |
| Data       | GitHub REST API                          |
| AI         | Ollama (local LLM inference)             |

## Architecture

```
Browser (React + TypeScript)
        │
        ▼
Spring Boot backend
        │
   ┌────┴────┐
   ▼         ▼
GitHub    Ollama
REST API  (local LLM)
```

The frontend never talks to GitHub or Ollama directly — every request goes through the Spring Boot backend, which handles both the external GitHub API call and the local AI inference call.

## Getting started

### Prerequisites

- Java 21+ and Maven
- Node.js 18+ and npm
- [Ollama](https://ollama.com/download) installed locally

### 1. Start Ollama

```bash
ollama serve
ollama pull llama3
```

Leave this running — the backend calls it at `http://localhost:11434`.

### 2. Run the backend

```bash
cd Backend/Github
./mvnw spring-boot:run
```

The API starts on `http://localhost:8080`.

### 3. Run the frontend

```bash
cd Frontend
npm install
npm run dev
```

The app runs on `http://localhost:5173` (default Vite port).

## Environment / configuration

If your GitHub API usage hits rate limits, add a personal access token to the backend config (`application.properties` or `application.yml`):

```properties
github.token=your_personal_access_token
```

If you want to use a different Ollama model, update the model name in `AiService.java` to match whatever you pulled with `ollama pull <model>`.
